# ADR 0003: Стиль REST та формат помилок

- **Статус:** Прийнято
- **Дата:** 2025-11-29

## Стиль REST
Ресурс `/items`, іменники в множині, HTTP-методи за призначенням:
POST (створення), GET (читання), PUT (оновлення), DELETE (видалення).

## Коди відповідей
- 200 — успішне читання/оновлення
- 201 — створено
- 204 — видалено
- 400 — помилка валідації
- 404 — ресурс не знайдено
- 500 — внутрішня помилка

## Формат помилки (ErrorResponse)
{ "error": "ValidationError", "code": "VALIDATION_FAILED",
  "details": [{ "field": "name", "message": "Name is required" }] }

## Відповідність контракту
Реалізація зобов'язана відповідати `docs/api/openapi.yaml`.
Зміни API спочатку вносяться в контракт.
