# ADR 0001: Стиль архітектури

- **Статус:** Прийнято
- **Дата:** 2025-11-05

## Контекст
Невеликий онлайн-магазин, один розробник, один застосунок на Node.js + SQLite.
Немає потреби в незалежних релізах окремих частин системи.

## Рішення
Продовжуємо як **модульний моноліт**: один застосунок, всередині розділений
на шари api / service / domain.

## Альтернативи
Мікросервіси: відкинуто, бо для поточного розміру команди й проєкту вони додають
складність (мережеві виклики, розгортання, розподілені дані) без користі.

## Наслідки
- Один репозиторій, один запуск (`npm start`), один реліз.
- Просте налагодження й тестування.
- Якщо проєкт сильно зросте, модулі можна буде виділити в сервіси.

## Умови перегляду
Повернутися до питання, якщо з'являться кілька команд, окремі вимоги
до масштабування модулів (наприклад, оплата) або незалежні релізи.
