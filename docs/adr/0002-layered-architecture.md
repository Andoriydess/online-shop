# ADR 0002: Шарова архітектура

- **Статус:** Прийнято
- **Дата:** 2025-11-29

## Структура
- `api/` — роути й обробка помилок: приймає HTTP-запит, викликає service,
  повертає відповідь за контрактом OpenAPI.
- `service/` — use-cases: валідація вхідних даних, виконання операцій,
  мапінг DTO <-> domain, робота з БД.
- `domain/` — сутності та їх інваріанти (Product, Order, ...).

## Напрямок залежностей
Зверху вниз: `api` -> `service` -> `domain`.

## Заборонені зв'язки
- `api/` не звертається до БД напряму.
- `domain/` не імпортує `api/` і `service/`.
- Уся бізнес-логіка та валідація знаходяться в `service/`.
