# Глосарій (Ubiquitous Language)

| Термін | Визначення |
|---|---|
| **User** | Особа, зареєстрована в системі, з роллю customer або admin. |
| **Product** | Товар у каталозі, який можна продати. Має назву, ціну й опис. |
| **Category** | Група товарів у каталозі (наприклад, «Одяг»). |
| **Cart** | Тимчасовий набір товарів, які покупець збирається купити. Не є замовленням. |
| **Order** | Зафіксоване замовлення: список позицій з цінами на момент покупки. |
| **OrderItem** | Позиція замовлення: товар, кількість і ціна на момент оформлення. |
| **Payment** | Спроба оплати конкретного замовлення (у проєкті лише імітація). |
| **Delivery** | Доставка оплаченого замовлення за вказаною адресою. |

## Терміни з різним значенням у піддоменах

- **Item**: у каталозі це `Product` (товар), у кошику `CartItem`, у замовленні
  `OrderItem`. Тому ми не використовуємо слово «item» без уточнення.
- **Price**: у каталозі це актуальна ціна товару, у замовленні `unitPrice`
  зафіксована на момент покупки й не змінюється після зміни ціни в каталозі.
- **Status**: у `Order`, `Payment` і `Delivery` статуси різні й не змішуються.
